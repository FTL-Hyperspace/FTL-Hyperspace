## 하이퍼스페이스란

지금까지 FTL 모딩은 제약이 매우 심했습니다. 이미 있는 요소를 바꾸거나 교체하는 것만
가능했고, 새로운 요소는 아주 좁은 범위 안에서만 추가할 수 있었습니다. 하이퍼스페이스는
모드 제작자가 그 한계를 넘어설 수 있게 해줍니다.

간단히 말해 FTL: Hyperspace 는 지금까지 불가능했던 기능을 가진 모드를 만들 수 있게 해주는
API 입니다. 고유한 장단점을 지닌 새로운 종족, 새로운 시스템과 보조 시스템, 서로 합쳐지거나
숨겨진 보조장비, 직접 만든 드론, 새로운 특수 상점과 명령 콘솔, 그리고 Lua 스크립트 지원
등이 그 예입니다.

[FTL: Multiverse](link:multiverseForum) 와 [Insurrection+](link:insurrectionForum) 같은
최신 프로젝트들이 하이퍼스페이스를 기반으로 삼는 이유입니다.

하이퍼스페이스는 제작자를 위한 API 로 설계되었지만, 그것만으로도 쓸모 있는 편의 기능도
몇 가지 함께 제공합니다.

<Card title="원작, 그러나 더 낫게" icon="rocket">

| 기능 | 하는 일 | 기본값 |
| --- | --- | --- |
| **시드 런** | 같은 시드로 겨루거나 특별한 판을 공유할 수 있습니다 | 켜짐 |
| **숫자 선체 표시** | 아군과 적군 모두 정확한 수치로 표시됩니다 | 켜짐 |
| **성능 개선** | 이미지를 필요할 때 불러와 로딩이 훨씬 빠르고 메모리도 덜 씁니다 | 켜짐 |
| **디스코드 리치 프레즌스** | 무엇을 플레이 중인지 보여줍니다 | Windows 빌드 |
| **자세한 툴팁** | 승무원과 이벤트 툴팁이 원작보다 많은 정보를 보여줍니다 | 일부 |
| **버그 수정** | 해킹 드론, 수리 드론, 크리스탈 파편, 방어 드론 | 일부 |
| **타일 단위 승무원 조작** | 타일 하나까지 정확하게 배치할 수 있습니다 | 꺼짐 |

모두 `hyperspace.xml` 의 설정 항목이므로, 모드가 꺼져 있는 기능을 켤 수 있습니다.

Windows, macOS, Linux 에서 네이티브로 동작하며 SteamOS 도 지원합니다.

## 모드 제작자용 문서

하이퍼스페이스가 제공하는 기능은 대부분 `Hyperspace.ftl` 안의 `data/hyperspace.xml` 에
문서화되어 있습니다. 일반적인 모드라면 간단한 `hyperspace.xml.append` 를 사용해 기존
태그를 추가하거나 수정하면 됩니다. FTL: Multiverse 같은 대규모 개편 모드는 자체
`hyperspace.xml` 을 함께 배포합니다.

사용자가 하이퍼스페이스를 별도로 내려받아 먼저 적용한다는 전제로 모드를 배포해주세요. 다른
모드와의 호환성을 위해 하이퍼스페이스의 리소스 파일이나 바이너리를 함께 재배포하지 마시고,
다운로드 위치만 안내해주시기 바랍니다.
