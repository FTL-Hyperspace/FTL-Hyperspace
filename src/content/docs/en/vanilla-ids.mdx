title: "Vanilla ids"
description: "Every id for vanilla FTL debug console"
---

These ids are arguments for [console commands](../console/).

Open the console in-game by pressing `` \ `` (rebindable in the hotkey
settings) and type the command with an id like so:

```sh
SECTOR ROCK_SECTOR
```

Each section below starts with the command its ids belong to.

The list is vanilla FTL's. Mods add their own ids on top. Check the mod's
files or wiki for those.

## Races

```sh
CREW <race>  # spawn a crew member
```

`energy` is Zoltan, `anaerobic` is Lanius, `battle` and `repair` are the
boarding and repair drones in crew form.
