<Steps>

1. ### Steam settings

   Skip this if you did not buy FTL on Steam.

   <SteamSettings />

2. ### Roll FTL back to 1.6.9

   <Rollback />

3. ### Install the Hyperspace binary

   Download `FTL.Hyperspace.x.xx.x-Windows.zip` from the [latest release](link:releases)
   and extract it. Inside you will find:

   <FileTree>
   - Hyperspace.ftl        keep this for step 5
   - README.txt
   - **Windows - Extract these files into where FTLGame.exe is/**
     - Hyperspace.dll
     - xinput1_4.dll
   </FileTree>

   Copy both files from that folder into your FTL folder, next to `FTLGame.exe`.
   Leave `Hyperspace.ftl` where it is for now.

   <FindFolder />

4. ### Set up a mod manager

   <ModManager />

5. ### Patch Hyperspace in

   Put the `Hyperspace.ftl` from the ZIP into your manager's `mods` folder, tick it, and apply.
   Tick any other Hyperspace-based mods after it.

   <Aside type="caution" title="Installing Multiverse instead?">
   Skip this step. Multiverse already contains Hyperspace, and patching both breaks
   the game. Go straight to step 6, then follow the Multiverse section below.
   </Aside>

6. ### Check it worked

   <Verify />

   <Aside type="danger" title="Error mentioning AcheivementTracker">
   FTL did not downgrade to 1.6.9 successfully. Run the rollback again and confirm
   `FTLGame_orig.exe` was created.
   </Aside>

</Steps>

Hyperspace is now installed and ready to play. Everything below is optional.

## Uninstalling

<Steps>

1. ### Put `ftl.dat` back to vanilla

   <Unpatch />

2. ### Remove the Hyperspace files

   Delete `Hyperspace.dll` and `xinput1_4.dll` from your FTL folder.

3. ### Undo the rollback

   To go back to 1.6.14, delete `FTLGame.exe` and rename `FTLGame_orig.exe` back to
   `FTLGame.exe`.

</Steps>
