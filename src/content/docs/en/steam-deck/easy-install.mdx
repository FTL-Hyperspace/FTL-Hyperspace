ftlman is the mod manager built for Hyperspace. It downloads whichever Hyperspace
release you pick, applies it to your copy of FTL, and keeps your mods in one list you
can reorder and re-apply whenever you like. The Deck runs the native Linux build, so
nothing needs downgrading, but you will need desktop mode to run ftlman.

<Steps>

1. ### Switch to desktop mode

   Press the **Steam** button, then **Power**, then **Switch to Desktop**.

2. ### Steam settings

   <SteamSettings />

   <Saves />

3. ### Set up ftlman

   <Ftlman />

4. ### Install Hyperspace

   <FtlmanHyperspace />

5. ### Add your mods

   <FtlmanMods />

   <Aside type="caution" title="Installing Multiverse?">
   Leave your mods out for now and follow the Multiverse section below instead.
   </Aside>

6. ### Check it worked

   <Verify />

</Steps>

**Hyperspace is now installed.** Return to gaming mode and launch FTL as usual.
Everything below is optional.

## Updating

Open ftlman in desktop mode, pick the newer release from the **Hyperspace** dropdown
and press **Apply**. Your saves are not affected.
