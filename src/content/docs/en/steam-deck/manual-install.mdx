<Aside type="tip" title="There is an easier way">
[ftlman](../easy-install/) does all of this for you. Only continue if you would rather
place the files yourself, or you want to understand what it does.
</Aside>

<Steps>

1. ### Switch to desktop mode

   Press the **Steam** button, then **Power**, then **Switch to Desktop**.

2. ### Steam settings

   <SteamSettings />

   <Saves />

3. ### Install the Hyperspace library

   <HyperspaceLinux />

4. ### Set up a mod manager

   <ModManager />

5. ### Patch Hyperspace in

   Put the `Hyperspace.ftl` from the ZIP into your manager's `mods` folder, tick it, and apply.

   <Aside type="caution" title="Installing Multiverse instead?">
   Skip this step. Multiverse already contains Hyperspace, and patching both breaks
   the game.
   </Aside>

6. ### Check it worked

   <Verify />

</Steps>

Hyperspace is now installed. Return to gaming mode and launch FTL as usual.
