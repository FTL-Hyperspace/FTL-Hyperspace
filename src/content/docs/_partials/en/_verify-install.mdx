Launch FTL. About halfway through the loading screen, and again on the menu, a small
version string appears in the **top right**. That is Hyperspace reporting itself, and
it means the binary is loaded.

If your mod's main menu comes up with no errors, you are done.

<Aside type="danger" title="No version string">
Hyperspace is not loading at all. Check if you have copied all files in the right folders again.
</Aside>

<Aside type="danger" title="Error mentioning hyperspace.xml">
The `Hyperspace.ftl` mod was not patched in. Run mod manager again and verify either Multiverse mod files or hyperspace.ftl is selected and patched
</Aside>
