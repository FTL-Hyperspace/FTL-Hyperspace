<Aside type="tip" title="Keep a vanilla copy">
Duplicate `FTL.app` somewhere outside the game folder before you patch anything. The
copy will stay vanilla, so you can launch modded and vanilla versions whenever you like without
unpatching, and it doubles as a clean source if an install goes wrong.
</Aside>
