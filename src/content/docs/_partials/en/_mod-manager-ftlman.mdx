**Ftlman** is the recomended mod manager for FTL: Hyperspace modding. 
Actively maintained and supports Hyperspace updates

1. Download the build for your machine from [the ftlman releases page](link:ftlmanReleases).
2. Extract the `ftlman` folder anywhere you like. It does not have to live in your FTL directory.
3. If FTL is currently modded, revert it to vanilla first.
4. Run `ftlman`. A Steam install is detected automatically; otherwise open **Settings** and paste your FTL folder into **FTL data directory**.
