
The original manager, now deprecated.

<Aside type="caution" title="Use ftlman instead">
We recommend ftlman for any new installation. Only use Slipstream if you have a
specific reason to.
</Aside>

1. Make sure FTL is vanilla before installing or upgrading Slipstream. Check `ftl.dat`: roughly 270 MB, or 212 MB on GOG. Much larger means mods are still patched in.
2. [Download Slipstream 1.9.1](link:slipstreamForum).
3. Extract it to a folder you will keep. Do not run it from inside the ZIP.
4. Java must be installed.

<Aside type="caution">
Slipstream 1.9.1 does not check whether `ftl.dat` is actually vanilla. It treats
whatever it finds on first run as the baseline. Starting from a modded file causes
problems
</Aside>
