## Ce que fait le mod

Le modding natif de FTL ne permet que de réagencer ce que le jeu contient déjà.
Hyperspace modifie le jeu lui-même et lève cette limite.

Les mods peuvent alors ajouter de nouvelles espèces avec leurs propres statistiques et
capacités, un nombre illimité de vaisseaux, des systèmes et sous-systèmes inédits, des
augmentations qui se combinent pour en former de nouvelles, des drones, des boutiques et
des événements sur mesure, ainsi que des scripts Lua pour des comportements hors de
portée d'un simple patch.

C'est pour cela que [FTL: Multiverse](link:multiverseForum) et presque tous les autres
grands mods en dépendent.

Installé seul, il apporte déjà les runs seedées à partager ou à disputer, un indicateur
numérique de coque, l'intégration Discord Rich Presence et une longue liste de
correctifs pour des bugs du jeu de base.

Il fonctionne nativement sous Windows, macOS et Linux, Steam Deck compris.

## Pour les créateurs de mods

L'essentiel de ce qu'expose Hyperspace est documenté dans `data/hyperspace.xml`, à
l'intérieur de `Hyperspace.ftl`. Utilisez un `hyperspace.xml.append` et ajoutez les tags
dont votre mod a besoin.

Publiez votre mod en partant du principe que le joueur téléchargera Hyperspace
séparément et l'appliquera en premier. Pour une compatibilité maximale avec les autres
mods, ne redistribuez pas les fichiers de ressources ni les binaires d'Hyperspace :
renvoyez simplement vers le téléchargement dans votre message sur le forum.

L'API Lua à partir de la version 1.2.0 se trouve dans le [wiki](link:wiki), avec le
reste de la documentation destinée aux développeurs. Les améliorations sont les
bienvenues : ouvrez une issue sur GitHub avec un extrait en markdown ou un lien vers un
clone du dépôt du wiki.
